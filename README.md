# Link Website

A single-page link hub that collects all my social links in one place.

- `index.html` is the whole site: HTML, CSS and JS in one file, no build step.
- Links open in a new tab.
- Custom eggplant cursor with a falling white sparkle trail. The trail is off for touch devices and reduced-motion users.

## Editing links

Find the `<ul>` in `index.html` and change each `href` and label.

## Hosting

Any static host works. On GitHub Pages: Settings → Pages → deploy from the `main` branch, root folder.
